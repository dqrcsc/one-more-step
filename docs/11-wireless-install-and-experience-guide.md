# 11. 无数据线安装、配对与全功能体验指南（小米手机 + Mac）

我已经在 Mac 宿主端专门为你内置了一个 **「局域网无线安装与一键配对网页台 (`/install`)」**。即使手头**没有任何数据线**，也完全不需要通过微信/钉钉传文件（避免微信把 `.apk` 重命名为 `.apk.1` 拦截安装），只需 **1 分钟** 即可在小米手机上完成无线安装与绑定。

---

## 第一阶段：无数据线安装 APK 到小米手机（二选一）

### 方式 A（最推荐 · 30 秒搞定）：手机浏览器直连 Mac 无线安装台

#### 1. 在 Mac 终端启动配对与无线下载服务
打开 Mac 终端，在项目根目录运行以下命令：
```bash
bun run setup && bun run oms pair
```
终端会立即启动后台守护进程 `omsd`，并打印出类似下面的信息：
```text
==============================================================
🔗 OneMoreStep · 小米手机无线安装与绑定凭证 (10分钟内有效)
==============================================================
📲 【无数据线安装 & 一键复制配对台】(手机浏览器打开):
   👉 http://192.168.x.x:19527/install

📌 6位配对码 (PIN):  839201
🌐 本机局域网地址:   192.168.x.x : 19527
🔑 完整配对 URI:
   oms://pair?v=1&id=mac_...
==============================================================
```

#### 2. 小米手机打开无线安装台页面
1. 确保你的小米手机与 Mac 连接在**同一个 Wi-Fi** 下。
   > 💡 **常驻 VPN 提示**：如果你的小米手机正开着 Clash / Sing-box 等 VPN 软件，请确保开启了「绕过局域网 / Bypass LAN」，或者在浏览器下载这 10 秒钟内暂时关一下 VPN 开关。
2. 打开小米手机自带浏览器（或 Chrome），在地址栏输入终端里显示的 **`http://192.168.x.x:19527/install`**。
3. 在打开的深色网页中：
   - **第一步**：点击蓝色按钮 **`[📥 点击下载 OneMoreStep.apk]`**（局域网速度约 30~50 MB/s，1 秒下完），直接安装。
   - **第二步**：点击绿色按钮 **`[📋 一键复制配对链接]`**（网页已自动将当前 Mac 的完整加密配对串复制到你手机剪贴板，免去手动输入！）。

---

### 方式 B（备选高阶）：使用小米「无线调试 (Wireless ADB)」免线直装

如果你想用 ADB 无线安装（**好处是：通过 ADB 安装的 APK 会被系统视为开发者信任应用，直接免去 Android 13/14/15 的“受限制的设置”解锁步骤**），同样不需要数据线：

1. 在小米手机上进入：**`设置 ➔ 更多设置 ➔ 开发者选项 ➔ 无线调试`**（开启开关）。
2. 点击 **「使用配对码配对设备」**，手机屏幕会弹出一个 **6 位 WLAN 配对码** 和 **IP:端口（例如 `192.168.1.50:38123`）**。
3. 在 Mac 终端运行：
   ```bash
   # 1. 配对无线 ADB（将 IP:端口 和 配对码 替换为手机弹窗显示的数值）
   adb pair 192.168.1.50:38123

   # 2. 连接无线调试主端口（注意看手机『无线调试』主页面顶部显示的 IP和端口，如 192.168.1.50:41555）
   adb connect 192.168.1.50:41555

   # 3. 无线静默安装 OneMoreStep.apk
   adb install -r android-app/app/build/outputs/apk/debug/app-debug.apk
   ```

## 第二阶段：小米手机首次绑定与满血权限配置（仅需一次）

### 1. 完成 Mac 绑定
1. 打开手机桌面上的 **`OneMoreStep`**。
2. 在顶部的 **「🔗 绑定 Mac 宿主」** 输入框中，长按**粘贴**刚才在网页里一键复制的 `oms://pair?v=1&...` 链接。
3. 点击 **`[立即验证并绑定]`**：
   - 手机弹出 Toast：`成功绑定 MacBook Pro`；
   - 顶部状态栏立即变为：**`🟢 局域网高速直连 (Tier 1)`**！
4. **常驻 VPN 分流设置（重要）**：
   - 打开你手机上常驻的 VPN 软件（如 Clash Meta / Sing-box / NekoBox），进入 **「分应用代理（Per-App Proxy）」**，找到 **`OneMoreStep`** 并将其勾选为 **「绕过代理 / 直连」**。此后即使你全天候挂着 VPN，OneMoreStep 也能毫秒级直连 Mac！

### 2. 开启小米 HyperOS / MIUI 专属权限向导
点击 App 右上角的黄色按钮 **`[小米权限]`**，展开自检面板并依次点 **`[去开启]`**：

| 序号 | 权限项 | 在小米设置页中的操作方法 | 作用 |
| :---: | :--- | :--- | :--- |
| **1** | **小米「后台弹出界面」与「锁屏显示」** | 点击 `[去开启]` 会直接跳进小米专属权限页，将 **「后台弹出界面」** 和 **「锁屏显示」** 设为 **始终允许**。 | 让 AI 能在后台静默帮你创建小米系统原生闹钟，以及在控制中心秒读剪贴板。 |
| **2** | **电池省电策略设为「无限制」** | 点击 `[去开启]` ➔ 选择 **「无限制」**。 | 防止锁屏后连接被小米系统休眠断开。 |
| **3** | **悬浮窗权限** | 点击 `[去开启]` ➔ 找到 `OneMoreStep` 开启「显示在其他应用的上层」。 | 用于截屏后右上角弹出 3.5 秒「🚀 发给 Mac AI」胶囊，以及 AI 操控屏幕时的顶部急停按钮。 |
| **4** | **无障碍服务** | • 若用**方式 A（浏览器）**安装，首次点无障碍若提示「受限制的设置」，请先去：**`手机设置 ➔ 应用设置 ➔ 应用管理 ➔ OneMoreStep ➔ 右上角三个点 ⋮ ➔ 允许受限制的设置`**（验证锁屏密码）。<br>• 然后回到无障碍设置 ➔ **已下载的应用 ➔ OneMoreStep 屏幕协同助手 ➔ 开启**。 | 赋予 Mac AI 读取手机控件语义树、零弹窗静默截屏与自动化点击能力。 |
| **5** | **小米「自启动」开关** | 点击 `[去开启]` ➔ 开启 `OneMoreStep` 的自启动，并在多任务界面下拉卡片加锁。 | 手机重启后自动恢复后台协同。 |

## 第三阶段：7 大核心场景逐个体验指南

绑定并开启权限后，你可以按以下顺序亲手体验所有核心功能：

### 体验 1：手机三指截屏 ➔ 1 秒飞入 Mac 收件箱（含语音附言）
1. 在小米手机任意界面（比如桌面或浏览器）**三指下拉截屏**。
2. 截屏瞬间，手机屏幕右上角会自动浮现一个半透明胶囊：**`[🚀 发给 Mac AI] [🎙️附言]`**（如果你不理它，3.5 秒后会自动消失，绝不烦人）。
3. 点击 **`[🚀 发给 Mac AI]`**（或点 `🎙️附言` 说一句“帮我看看这个界面布局”）。
4. 回到 Mac 查看收到的内容（三种直观方式任选）：
   - **自动即时联动**：如果你发的是文字，它已经**自动复制进了 Mac 剪贴板**（直接按 `Cmd+V` 即可粘贴）；如果发的是图片/截图，Mac 会**自动弹出预览窗口**展示大图！
   - **Mac 实时收件箱 Web 看板**：在 Mac 终端运行 `bun run oms web`（或浏览器打开 [`http://127.0.0.1:19527/inbox`](http://127.0.0.1:19527/inbox)），即可直观看到图文卡片流、点击放大原图、一键在 Finder 定位或反向给手机发消息。
   - **命令行查看**：
     ```bash
     bun run oms inbox
     ```
     你会看到刚刚那张截图已经落盘在 `~/.one_more_step/inbox/YYYY-MM-DD/` 下，且附带了你的语音文字！

### 体验 2：任意 App 系统分享 ➔ 置顶直达「个人知识库」
1. 在手机浏览器、知乎、公众号或相册里点击 **「分享」**。
2. 在小米系统分享面板中，你会看到 **`OneMoreStep`** 提供了 **3 个专属置顶入口**：
   - **`📚 存入个人知识库`** (`#pkb_vault`)
   - **`🚀 发给 Mac Inbox`** (`#default_inbox`)
   - **`🐛 发给 AI 修 Bug`** (`#ui_bug`)
3. 点击 **`📚 存入个人知识库`**，然后对电脑上的 Antigravity / Codex 说：*“看看我刚从手机发过来的知识库素材”*。

### 体验 3：小米控制中心快捷磁贴（1 秒同步剪贴板 & 语音闪念）
1. 从小米手机右上角下拉打开 **控制中心** ➔ 点击编辑按钮 ➔ 在底部未添加磁贴中找到 **`发给 Mac AI`** 拖入控制中心。
2. 在手机任意地方复制一段文字，然后下拉控制中心**单击 `发给 Mac AI` 磁贴**：
   - 手机瞬间通过 1×1 透明焦点窗口读取剪贴板并弹出提示：`📋 剪贴板已同步至 Mac AI`！
3. **长按该磁贴**：直接呼出「💡 我有一个想法」语音闪念框，说完点发送直接进入 Mac 端 `#voice_idea` 队列。

### 体验 4：电脑端一行命令为小米手机定原生闹钟、写日历、发强提醒/语音播报
在 Mac 终端依次运行以下命令，观察你手边的小米手机：
```bash
# 1. 静默在小米原生时钟 App 里创建一个闹钟
bun run oms alarm 08:30 --label "起床检查 AI 任务结果"

# 2. 查询你小米手机未来 3 天的日历日程（自动展开重复例会）
bun run oms calendar list

# 3. 向小米系统日历写入一条新日程（带提前 15 分钟提醒）
bun run oms calendar add --title "OneMoreStep 架构复盘" --desc "验证跨端协同"

# 4. 发送一条 L3 突破勿扰强触达通知，并让小米手机直接用闹钟声道开口说话（TTS）！
bun run oms notify "注意，代码重构与单元测试已全部通过，请确认是否合并" --level urgent --tts
```

### 体验 5：将电脑上的报告推送到手机「🎧 通勤 TTS 随身听」
在 Mac 终端运行：
```bash
bun run oms push ./docs/02-scenarios-and-value.md --title "OneMoreStep 全景场景分析" --tts
```
看你的小米手机 `OneMoreStep` 主界面时间流：立即出现该文档卡片，点击卡片底部的 **`[🎧 TTS 通勤朗读 (1.2x)]`**，手机立即清洗掉 Markdown 符号并开始用自然中文语音为你朗读！

### 体验 6：离开工位时的「远程监工与交互式审批」
在 Mac 终端运行以下命令（模拟长耗时 Agent 遇到高风险操作请求你远程拍板，终端会进入挂起等待状态）：
```bash
bun run oms approve --title "是否执行生产数据库迁移？" --summary "将新增 2 张索引表，预计耗时 3 秒"
```
此时你的小米手机立即震动并弹出紫色审批卡片，在手机上点击 **`[✅ 批准继续]`**，你会看到 Mac 终端在 **10 毫秒内** 立即收到你的批准结果并继续向下执行！

### 体验 7：无障碍 GUI 屏幕观察与自动化操作（含物理急停胶囊）
先在手机上随便打开一个应用（比如设置或钉钉），然后在 Mac 终端运行：
```bash
# 1. 提取当前手机屏幕的紧凑语义控件树（并附带绘制了 #1, #2 红框角标的 SoM 截图）
bun run oms gui observe --screenshot --som

# 2. 让 AI 点击屏幕上的某个控件编号（例如 #2），同时观察手机顶部自动浮现的橙色『🤖 Mac AI 操作中 · 点击立即停止』安全胶囊！
bun run oms gui act click "#2"
```

## 第四阶段：接入 Antigravity / Codex / OpenCode

1. **安装全局 Skill 与 CLI**：
   运行 `bun run setup` 后，全局 Skill 会自动安装至 `~/.codex/skills/one-more-step/SKILL.md`（仓库模板位于 [`skills/one-more-step/SKILL.md`](../skills/one-more-step/SKILL.md)），所有读取 `~/.codex/skills` 的 Agent 会自动发现并掌握全套 `oms` 命令与工作流。
2. **挂载标准 MCP Server（可选增强）**：
   在支持 MCP 的客户端配置中加入：
   ```json
   {
     "mcpServers": {
       "one-more-step": {
         "command": "bun",
         "args": [
           "run",
           "/path/to/one_more_step/mac-host/src/mcp/server.ts"
         ]
       }
     }
   }
   ```
   配置完成后，你只需要直接用大白话对 AI 说：
   - *“看看我手机刚截的那张图”*
   - *“把我手机相册里最新拍的那张照片拉过来分析一下”*
   - *“帮我在手机上定个明天早上 8 点的闹钟，顺便看下我明天手机日历有没有空”*
   - *“把这个任务跑完后用语音播报提醒我手机”*
