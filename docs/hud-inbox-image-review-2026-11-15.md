# 投递页最大高度、置顶常驻和图片放大

日期：2026-11-15。与镜像适配修改一起提交，基线为 `bb8cbe0`。

## 用户截图与原因

截图选中“最近投递”，而上一轮最大高度只对“手机镜像”生效。这是实现范围不足；现将两个 Tab 的打开、恢复、切换以及跨屏均适配显示器 `visibleFrame` 高度，保留手动缩小。

真实 AppKit 属性探针确认：按钮开关会正确更新 `title` 与 `attributedTitle`，但 NSPanel 的 `hidesOnDeactivate` 在开关前后都为 `true`，窗口层级也一直是浮动层（3）。因此即使业务代码跳过失焦收起，系统仍会在切换 App 时隐藏窗口，开关也没有真实层级差别。

现显式关闭系统自动隐藏，由已有失焦规则管理收起；投递未钉住时为普通窗口层，钉住时进入浮动层并保留显示。按钮命名“置顶常驻”，增加行为提示。镜像保持浮动、失焦不收起，继续隐藏该投递专用按钮。

## 图片放大

单击投递图片打开独立原生查看窗；可使用 +、−、适应窗口、100%、滚动和 Esc。初始按显示器可用区域适配，图片不再通过固有尺寸撑大主窗口。支持回车/空格及无障碍激活，鼠标指针和提示说明点击能力。

查看窗打开时保留主窗；关闭图片回到投递。主窗关闭、切 Tab 或最小化时一并关闭图片查看窗。使用内存中的 NSImage，不修改原图、不启动外部 App。
