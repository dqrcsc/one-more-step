# v1.6.1 · 全栈安全加固、GUI Agent 防绕过护栏、Keystore 密钥保护与性能优化

基于双端代码诊断审查完成的 4 批次全栈安全加固、传输可靠性修复与性能优化升级。

### 核心升级与修复

- **Mac 宿主端安全加固与性能治理**：
  - **Web Dashboard 存储型 XSS 修复与 CSP 加固**：补齐 `escapeHtml` 单引号转义，移除卡片动态内联 `onclick="doAction(...)"` 拼接，统一采用 `data-item-action` 属性与事件委托；为 `/inbox`、`/dashboard`、`/mirror` 注入 `Content-Security-Policy` 与 `X-Content-Type-Options: nosniff`。
  - **私有目录与 Socket 权限收紧**：`~/.one_more_step` 目录强制 `0700`，`config.json` 与 `omsd.sock` / `bt.sock` 强制 `0600`；`config.json` 采用原子重命名写入，并在解析异常时自动备份为 `config.json.corrupt.<ts>.bak` 防止覆盖已配对设备；IPC Server Socket 补齐 `error` 监听。
  - **Inbox $O(1)$ 增量更新与日志自动轮转**：`InboxManager` 按变更项增量写入 `meta.json`；过滤 `/api/inbox` 高频访问日志，为 `omsd.log` 与 `connections.jsonl` 增加 2 MB 自动截断轮转。
  - **Swift 蓝牙桥修复**：移除硬编码个人 AirPods MAC，补齐 `SIGPIPE` 忽略与 `SO_NOSIGPIPE`，使用 `writeLock` 保护 `fd` 并发访问，修复 `CHAR_MAC_INFO_UUID` 读取时误清空 `txQueue` 的问题。
- **Android 端安全护栏与系统入口加固**：
  - **GUI Agent 防绕过护栏（`SensitiveActionPolicy`）**：坐标点击 (`click`/`long_click`) 强制要求携带 `observationId`，并对 `(x, y)` 最小包围盒命中节点及子树聚合文本执行敏感词拦截（触发 L2 确认浮窗）；将 `com.oms.client` 本包、支付/安装器/权限控制器及非蓝牙系统设置页纳入黑名单，遍历多窗口防止分屏/小窗绕过并拦截 `isPassword` 节点。
  - **全路径急停胶囊与本地恢复**：解锁、拨号、挂断、实时同屏手势全路径展示 `🛑 急停 AI` 胶囊；手势被用户触摸取消（`onCancelled`）时立即锁存急停，并在 `MainActivity` 顶部新增本地「▶️ 恢复 AI 操作」按钮。
  - **系统分享与短信入口加固（`ShareInputPolicy`）**：外部分享标签采用白名单校验（禁止伪造 `sms_otp`），拦截外部 `file://` 与 `sms`/`contacts`/`telephony` 等敏感 URI；修正 `AndroidManifest.xml` 中 `android.provider.Telephony.SMS_RECEIVED` 广播名，设置 `android:allowBackup="false"` 与 `dataSync|connectedDevice` 前台服务类型。
- **双端传输可靠性与 Keystore 密钥保护**：
  - 修复 `OmsTransportClient` 中 `isConnectingLan` 在 generation 过期退出路径未复位的重连死锁 Bug。
  - 增加 WebSocket 发送队列背压控制（大文件分片流控、同屏帧超 `1.5 MiB` 自动丢帧）及断连时自动停止屏幕镜像并释放 WakeLock。
  - 使用 Android Keystore (`AES/GCM/NoPadding`) 加密包裹 `pair_secret_enc`，兼容旧版明文密钥自动无感迁移。
- **Release 构建与主线程 I/O 减负**：
  - `build:apk` 切换为非调试版 `assembleRelease`（`debuggable=false`），默认兼容现有签名证书以支持小米 HyperOS 免卸载平滑覆盖升级；缓存 APK SHA-256 并将首帧哈希计算与分享附件落盘移至 `Dispatchers.IO`。
