# v3.6.4 - 2026-11-23 · 远程控制与同步可靠性修复

本版修复本轮诊断的 11 项问题。自动回归已通过，真机验收尚未完成。

### 升级前请注意

- **跨网远程解锁需要 Mac 与 Android 一起升级。** 新版 Mac 要求绑定连接、60 秒有效、单次使用的确认挑战；旧手机不支持回传挑战时会安全拒绝。局域网解锁保持现有交互。
- 聊天现在按 Mac 独立保存同步确认；首次切换到另一台已配对 Mac，会补齐手机上的非无痕历史。待发收藏绑定产生操作时的电脑，不随切机改投。
- 旧的未分设备缓存不猜测迁移；本地归档仍保留，来源不明的条目不会按编号请求当前电脑。
- 此 Release 不会自动更新本地运行中的 Mac 服务。无需卸载手机 App 或清除数据；APK 签名与上一版保持兼容。

### 修复内容

- **远程控制**：按请求实际认证连接判断安全策略，拒绝客户端链路提示降级；跨网确认加入连接绑定、超时和重复消费保护。生物识别仍由可信的已配对手机客户端执行，挑战不等同于硬件签名证明。
- **离线补发**：串行发送并只移除已确认的具体版本，保留发送期间新增及更新的条目，失败可重试。
- **聊天同步**：持续分批排空积压；按 Mac 和内容修订号确认，旧回执不吞新编辑；保留旧版数据库数据。
- **多 Mac 阅读**：尺素目录、正文、图片和本地投递合并按来源 Mac 隔离；切机、切页取消旧请求，缓存先展示再联网刷新。
- **知识库写入与读取**：收藏持久化幂等及中断恢复；相同操作不重复生成笔记；拒绝库外符号链接读取，不覆盖用户编辑内容。
- **文章匹配**：精确 URL 优先；标题仅允许唯一匹配，避免同名文章误命中。
- **配额与图片**：明确显示本地采样、过期和未知；图片在流读取期间限制体积，支持无长度头响应。
- 包含 v3.6.3 标签之后补充的 13 个 MCP 工具注解与端到端测试。
