# v3.6.7 - 2026-11-27 · OTA 更新进度条常驻显示与内置免 VPN 代理极速下载

本版修复手机端顶部 OTA 更新提示条点击「更新」后立即收起消失、以及在办公网 Wi-Fi AP 隔离环境下回退 GitHub 下载未走内置免 VPN 代理导致超时卡住的问题；同时完整包含 `v3.6.6` 的锁屏至解锁短信验证码双端四层防重推与近场蓝牙拥塞修复。

### 修复与优化内容

- **顶部 OTA 提示条进度常驻与错误重试反馈 (`CockpitShell`)**：
  - 补齐 `GlobalAmbientStatusBanner` 对 `OtaUiState.Downloading` 的状态映射，点击「更新」后提示条不再收起消失，而是实时展示下载进度百分比（`正在下载新版本 v… 42%`）并禁用重复点击。
  - `OtaUiState.Error` 独立显示琥珀色错误摘要与「重试」按钮，不再与普通待更新提示混淆。
- **GitHub OTA 接入内置免系统 VPN 代理 (`OmsTransportClient`、`VerifiedOtaInstaller` & `SmartRegionRouter`)**：
  - 内置分流路由新增 `github.com`、`api.github.com` 与 `*.githubusercontent.com` 规则，OTA 版本查询与 APK 下载优先走内置 `OmsProxyManager` 免 VPN 代理通道（节点异常自动回退直连；局域网 HTTP 因 AP 隔离中断时自动回退 GitHub HTTPS 并严格校验同一 SHA-256 与签名）。
  - 修复前后台切换自动检查更新在瞬时网络超时（`!res.ok`）时误清空已有待安装/待更新状态的问题。
- **包含 `v3.6.6` 全部修复**：锁屏至解锁验证码四层 30 分钟语义去重、HyperOS 解锁状态栏滚动残片拦截、`oms-bt-bridge` 拥塞高 CPU 空转与“手机值守”误锁屏修复。

### 安装包与升级说明

- **从 `v3.6.5` 升级至 `v3.6.7` 的方法**：由于旧版 `v3.6.5` 尚未接入内置代理下载 GitHub OTA，如当前处于 AP 隔离办公网，请**临时开启手机 VPN 后进入「青简 App → 右上角设置 → 应用版本」点击更新**（或在家庭无隔离 Wi-Fi 下直接更新）。升至 `v3.6.7` 后，后续更新在办公网免开 VPN 点击顶部横幅即可实时看进度秒速升级。
- `OneMoreStep-v3.6.7.apk`：包名 `com.oms.client`，versionName **3.6.7** / versionCode **70**，Android 11+，非调试包，签名与上一版保持兼容，无需卸载或清除数据。
