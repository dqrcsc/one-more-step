# v3.7.0 - 2026-11-28 · 全场景四模态 Mac 遥控舱、体感飞鼠激光笔与无损语音直输

本版将「Mac 远程操控」全面升级为 120Hz「眼看电脑大屏、手盲操手机」的四模态多指触觉遥控器与体感激光笔，让手机真正能完全脱离物理触摸板与键盘丝滑操控 Mac。

### 新增与升级亮点

- **四模态单手遥控舱 (`触控板 · 激光飞鼠 · 键盘语音 · 系统应用`)**：
  - **120Hz 多指触控板**：非线性指针加速（慢移精准微操、快甩跨多屏）、单指轻点/双击按住拖拽、独立 `[左键 · 拖拽锁 · 右键]` 微动条、双指右键、双指像素级平滑滚动 + 60fps 惯性滑行（触碰即刹停）、双指捏合缩放（`⌘+/⌘-`）、三指调度中心（Mission Control）与全屏桌面空间（Spaces）左右切换。
  - **体感飞鼠与全屏穿透激光笔/聚光灯**：中央拇指扳机采用「按住即指、松手即定格、随按自动归零防漂移、双击锁定常驻」人体工学设计（陀螺仪仅激活时采样，闲置零耗电，内置生理微颤死区滤波）；支持 **原生飞鼠光标 / 红点拖尾激光笔 / 聚光灯暗角高亮（可调光圈半径）** 三种效果，穿透全屏 Keynote / PPT / 浏览器空间且鼠标点击 100% 穿透。
  - **无损文字/语音直输与盲操快捷键矩阵**：手机输入法任意中英文、代码、Emoji 无损 UTF-16 直注 Mac 当前光标处（不受 Mac 输入法状态干扰，支持 `⏎ 自动回车`）；内置按住/轻点说话语音转文字直输 Mac；配备粘滞修饰键（`⌘/⇧/⌥/⌃`）、长按连发退格与十字方向键、高频系统快捷键及亮度/媒体键。
  - **手机物理音量键盲操联动**：在遥控面板内按手机实体音量 `+/-` 键，默认直接调节 Mac 系统音量，切至「激光飞鼠」页时自动充当 PPT/网页上下翻页键。
- **20B 紧凑二进制 `HID_INPUT (0x08)` 协议与常驻 Swift 原生引擎**：
  - 复用现有 AEAD v2 双向认证加密隧道（无需额外录屏权限或新增防火墙端口），双端内置屏障安全明文增量合批，局域网 120Hz、跨网与近场蓝牙同样丝滑不积压。
  - 内置 `1.8s` 激光/聚光灯断连看门狗自动消散、锁屏防盲注拦截与退出/断连自动释放按键拖拽锁保护。
