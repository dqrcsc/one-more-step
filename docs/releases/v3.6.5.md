# v3.6.5 - 2026-11-23 · 收藏队列防毒丸阻塞、本机 IPC 解锁恢复与切机蓝牙清理

本版基于 `v3.6.4` 代码审查结论，补充修复 3 项边界隐患，并包含 `v3.6.4` 的全部远程控制与多机隔离修复。

### 修复内容

- **博物图鉴重复入库幂等与离线队列防阻塞**：
  - Mac `promoteToVault` 计算幂等摘要 `digest` 时排除易变的请求时间戳 `createdAtMs`，使同一张博物图鉴卡跨时间二次点击“存入知识库”保持幂等成功；对真正修改内容的同 `itemId` 冲突及非法参数统一返回 JSON-RPC `-32602` 错误码并原样透传。
  - Android `ChatSyncQueue` 与 `CockpitRuntimeCoordinator` 区分网络/超时可重试错误与 `-32602` 确定性拒绝（Poison Pill），坏条目直接淘汰不入队、不阻塞后续待发收藏；同时为旧版缺少 `payload.itemId` 的待发记录在发送时自动补齐 `itemId`。
- **本机 CLI `oms mac-ctl unlock` 受信任 IPC 通路恢复**：
  - Mac 守护进程本地 Unix Socket IPC 入口显式标记 `activeTier: "LOCAL_IPC"` 并放行，修复手机处于 `DISCONNECTED` 或 `WAN_WEBRTC` 时本机终端解锁误触发跨网指纹挑战的问题；远端连接伪造 `LOCAL_IPC` 提示仍会被安全拦截。
- **Android 切换配对电脑时同步清理蓝牙 `BT_RFCOMM`**：
  - `switchToPairedMac` 在断开 `LAN_WS` / `WAN_WEBRTC` 的同时一并关闭 `activeBleGatt`，并将主动切机纳入正常关闭原因，避免残留旧电脑 BLE 连接或误记断线诊断告警。

### 安装包与升级说明

- **跨网远程解锁需要 Mac 与 Android 同步升级至 `v3.6.4+`（推荐 `v3.6.5`）。**
- `OneMoreStep-v3.6.5.apk`：包名 `com.oms.client`，versionName **3.6.5** / versionCode **68**，Android 11+，非调试包，签名与上一版保持兼容，可直接覆盖升级。
