# v3.7.1 - 2026-11-28 · 原生 Magic Trackpad 手势 1:1 对齐、纯 GPU 丝滑激光聚光灯与辅助功能自愈加固

本版针对真机高频遥控体验完成了两项核心升级与一项权限加固：将手机触控板的手感、加速曲线与多指手势 **1:1 对齐 MacBook 原生触控板**，并将体感飞鼠、红点激光笔与聚光灯升级为 **200Hz 陀螺仪采样 + Mac 120Hz 亚像素插值 + 100% GPU 零光栅化图层合成**，彻底消除 Retina 高分屏下的卡顿与掉帧。

### 核心优化与修复亮点

- **触控板手感与多指手势 1:1 原生对齐**：
  - **多指无缝衔接**：修复双指/三指抬落切换时的手势锁死问题（双指滚动后抬起一指可无缝继续单指移动光标；落指内置 `18ms` 防抖，双指点按不再引起首帧光标跳动）。
  - **原生单/双/三连击与防误触双击拖移**：新增 `CLICK_WITH_COUNT` 原生注入 `CGEvent` `clickState = 1/2/3`，精准支持单击、双击选词、三击选整段，彻底修复快速双击多发点击或误入拖拽状态的问题。
  - **Apple 原生滚动阶段 (`CGScrollPhase` / `CGMomentumScrollPhase`)**：完整注入 `Began / Changed / Ended` 与惯性 `Begin / Continue / End` 边界相位，原生支持 **Safari / Chrome 双指左右滑前进后退**、页面边缘橡皮筋回弹、触碰即刹停、双指双击智能缩放（`⌘+` / `⌘0`），并与双指捏合缩放严格互斥。
  - **三/四指全套桌面手势与大屏指针提速**：同时支持三指/四指上滑调度中心（Mission Control）、下滑应用窗口（App Exposé）、左右切换全屏桌面空间（Spaces），以及 **四指捏合打开启动台（Launchpad）、四指张开显示桌面**；重新标定非线性指针加速曲线，单拇指一划即可跨满 Retina 大屏，慢移保持像素级微操精度。
- **纯 GPU 丝滑激光笔、聚光灯与 200Hz ➔ 120Hz 追随插值**：
  - **零 CPU 像素重绘**：移除全屏透明窗口的 CPU `draw(_:)` 光栅化（原 Retina 全屏每帧重绘超过 `32 MB`），改为纯 GPU `CALayer` / `CAShapeLayer` 合成（预渲染高光激光点纹理、二次贝塞尔平滑流光尾迹、缓存聚光灯暗角光圈纹理并仅平移 GPU 图层坐标），Retina 大屏下丝滑满帧。
  - **200Hz 体感采样 + 双通道节拍器 + 120Hz 亚像素插值**：Android 端启用 `200Hz (5000μs)` 姿态采样与自适应双斜率滤波，修复发送协程提前唤醒导致的微抖动；Mac 端新增 `120Hz (8.33ms)` 亚像素追随插值器（静止自动停表 `0%` CPU，点击瞬间自动微秒级对齐目标坐标）。
- **macOS 辅助功能（TCC）版本升级自愈加固**：
  - 修复 `~/Applications/青简控机助手.app` 升级二进制（Build `68`）后因 Ad-hoc 签名变更导致的“辅助功能开关看似开启但实际失效”以及文字/语音发送反复弹出系统设置的问题。
