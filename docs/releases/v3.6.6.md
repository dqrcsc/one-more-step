# v3.6.6 - 2026-11-27 · 锁屏至解锁验证码双端防重推与近场蓝牙拥塞修复

本版重点解决小米 HyperOS 锁屏收到短信验证码后、间隔数分钟解锁手机再次触发 Mac 重复推送的问题，并包含 `v3.6.5` 之后修复的近场蓝牙 `oms-bt-bridge` 拥塞高 CPU 空转与“手机值守”误锁屏修复。

### 修复与优化内容

- **锁屏至解锁短信验证码四层防重推（Android + Mac 双端协同）**：
  - **拦截解锁滚动残片与旧通知重发**：当 `OmsNotificationListenerService` 在线时，`OmsAccessibilityService` 不再重复消费 `TYPE_NOTIFICATION_STATE_CHANGED`，彻底消除解锁瞬间状态栏滚动摘要（如 `…您的验证码是: 192268`）引发的二次上报；同时过滤 `FLAG_GROUP_SUMMARY` 群组摘要、校验通知原始到达时间 `notif.when`（超过 5 分钟有效期的解锁脱敏重发通知直接忽略），并维护 `sbn.key -> code` 30 分钟去重表。
  - **短信库高水位防重扫**：`SmsContentObserver` 启动时记录 `content://sms/inbox` 当前最大 `_id` 高水位并维护已处理 ID 集合，防止解锁点开短信（`read=0 -> 1`）触发数据库变更回调时重复扫描。
  - **Android 持久化两级语义去重**：`OtpExtractor` 由 25 秒纯内存去重升级为 `SharedPreferences` 持久化的两级去重（60 秒跨通道突发合并 + 30 分钟验证码后缀上下文指纹 `normalizeOtpContextTail` 匹配），即使进程重建或头部签名被截断也能精准去重，同时保留不同品牌签名同码的独立放行。
  - **Mac `omsd` 30 分钟语义兜底去重**：`InboxManager.findRecentDuplicateOtp` 在入库前比对 30 分钟内的同码、品牌签名与归一化后缀指纹；命中重复时静默抑制重复落盘、桌面通知弹窗和剪贴板覆盖，并正常回传 `{ ack: true, deduplicated: true, savedId: clientItemId }` 核销手机端 Outbox 队列。
- **近场蓝牙 `oms-bt-bridge` 防空转与防截断修复**：
  - 修复办公 Wi-Fi 开启 AP 隔离回退至 BLE 链路时，`updateValue` 返回 `false` 背压导致的 `oms-bt-bridge` 170% CPU 空转及 200–300 KB 同步突发包溢出截断 AEAD 序列号问题，避免近场 RSSI 心跳饥饿误触发“手机值守”锁屏。

### 安装包与升级说明

- **升级 Mac 服务**：拉取最新代码后执行 `bun run build:bt && oms daemon restart` 即可生效。
- **升级 Android 客户端**：可通过 `oms ota` 一键无线覆盖升级，或下载下方 `OneMoreStep-v3.6.6.apk` 安装（包名 `com.oms.client`，versionName **3.6.6** / versionCode **69**，Android 11+，非调试包，签名与上一版保持兼容，无需卸载或清除数据）。
