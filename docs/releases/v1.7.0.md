# v1.7.0 · 青简合一：并入微信尺素（WeChat-as-Context）与四端统一工作台

将 **青简·尺素 (`wechat-context`)** 完整并入 `one-more-step` 单仓库与单一 `omsd` 守护进程体系，实现本地一套常驻服务同时承载小米 Android 双向协同与手机微信 ClawBot 上下文桥接。

## 主要新增与改进

- **单守护进程与受管子进程隔离 (`WeChatBridgeSupervisor`)**：
  - `omsd` 在后台自动拉起、守护并回收 `wechat-context` 子进程（内置父进程存活看门狗与 `BUN_CONFIG_DNS_TIME_TO_LIVE_SECONDS=0` 注入），本地数据目录统一收敛至 `~/.one_more_step/wechat/`；
  - 所有 `/wechat/*` 与 `/api/wechat/*` 接口均受 `127.0.0.1` 回环与同源守卫保护，非回环请求一律返回 `403 Forbidden`。
- **Mac 原生菜单栏与悬浮窗 (`oms-mac-hud`) 升级**：
  - 浮窗顶部新增独立 **「💬 微信尺素」Tab**（与「📬 最近投递 / 📱 手机镜像」并列），支持直接浏览归档文章、切换查看「伴读笔记 / 初筛摘要 / 归档原文」、一键同步至手机通勤朗读及 Finder 定位；
  - 修复侧边栏多行换行标题点击被 `NSTextField` 文本选择拦截的问题，补齐真实 AppKit `hitTest` 回归；新增图片独立预览浮窗缩放控制；
  - 右上角轻通知卡支持翠绿色「💬 青简·尺素」通道标识，菜单栏右键菜单同步展示手机与微信双通道在线状态。
- **Mac 本地 Web 总控台与小米手机时间流扩展**：
  - `http://127.0.0.1:19527/inbox` 顶部新增「📬 手机协同流 / 💬 微信尺素 / ⚙️ 尺素模型与路由配置」模块切换及「推送到手机微信」入口；
  - Android 客户端（v1.7.0 / build 43）时间流新增独立 **「💬 微信尺素」Tab** 与专属翠绿伴读卡片，支持耳机通勤 TTS 朗读及离线待发队列重连自动补推。
- **统一 CLI 与渐进式单入口 Skill**：
  - `oms` 新增 `oms wx <subcommand>`（保留 `wx-ctx` 兼容命令）；
  - 全局 Skill 收敛为单入口 `one-more-step` 配合 `references/wechat-context-rules.md` 按需加载。
