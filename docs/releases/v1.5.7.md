# v1.5.7 候选版 · AirPods 切换期限与拨号盘冷启动修复

**状态：Mac 与手机已更新到 v1.5.7，尚未发布 GitHub。拨号盘及 AirPods 正常往返通过，但后续扩展测试发现 AirPods 超时后的自动恢复仍不稳定；本版不能宣称该问题彻底修复。**

## 本次修改

- **拨号盘首次打开**：由固定等待 520ms 后检查一次，改为最多 3 秒、每 100ms 核验拨号包与号码；每一步保留锁屏、急停、会话及总期限保护。未增加自动拨出或坐标点击回退。
- **AirPods 等待预算**：Mac 原生连接最多 22 秒，桥接等待 23 秒；Mac 释放最多 7 秒、桥接等待 8 秒；手机连接最多 8 秒、Mac RPC 等待 9 秒；CLI/IPC 整体等待 35 秒，给阶段间回复留余量。
- **超时及取消**：Mac 超时向原生桥发送取消，断开宿主连接及新原生请求会使旧操作失效，过期操作不能继续重试或改变默认输出。Android 直接执行有期限、可取消的挂起流程，删除无界阻塞 RFCOMM 兜底，不再让 4.2 秒回调等待先于实际连接流程结束。
- **结果确认**：Mac 需确认目标蓝牙连接、以蓝牙地址匹配 CoreAudio UID 的目标输出设备和默认输出；Android 按当前媒体/通话模式确认相应活动蓝牙设备，不能仅凭 ACL 连接或任意 AirPods 输出认定成功。系统不提供可验证活动设备时返回“未确认”，保守失败。
- **目标与释放**：明确传入 MAC 时，未配对就失败，不回退其他耳机；释放只针对指定设备。手机释放和 Mac 自动释放回复均以实际结果为准。
- **手动请求竞争**：已有手动切换时拒绝另一项手动切换，避免阶段交错；手机接管命令绑定最初的连接会话。

## 升级方式

- 候选版本 **1.5.7 / versionCode 31**，APK 仍为 Android Debug 签名；两端应一起更新，配对协议与数据结构不变。
- 保留数据覆盖安装，不卸载、不清除数据。Mac 端需要重新构建原生桥并重启守护进程。
- 系统已经接受的蓝牙连接请求无法保证撤回；本次保证停止应用侧后续步骤、拒绝迟到成功，不宣称物理连接必然回滚。
- Android 隐藏蓝牙 API 与 macOS 音频设备信息存在系统差异，本次只验证当前这台手机、Mac 和 AirPods 4；不代表其他设备均兼容。

## 扩展真机结果与已知问题

- **并发通过**：向 Mac 切换进行中提交相反请求，第二项返回 `ok=false/stage=busy`；原请求正常完成，随后恢复手机成功。
- **不存在目标通过**：确认测试地址未配对后，分别请求切到 Mac/手机，两端均失败，原 AirPods 4 手机连接保持不变，没有回退其他耳机。
- **真实不可用超时通过**：用户将两只耳机入盒合盖。Mac 在 22049ms、手机在 8194ms 返回失败，两端均未连接。随后 25.644 秒、6 次实时查询没有观察到迟到连接或默认输出变化。这是有限观察窗口，不是永久无迟到行为的保证。
- **恢复未通过**：用户出盒并佩戴后，到 Mac 22483ms 超时、回手机 3319ms 成功；再从已确认手机连接状态做一次对照，到 Mac 22462ms 超时、回手机 8139ms 失败。没有持续重试。
- **已恢复用户使用**：用户在手机系统蓝牙中手动连接成功，实时状态确认 PHONE。测试后不再自动切换。
- **待修问题**：超时/不可用后的程序化恢复连接不稳定。现有结果不能确定是连接调用、系统 profile、音频路由确认或阶段竞争，需要记录底层返回码和阶段证据后定位；不应仅继续扩大等待或声称已根治。

## 后续真机验收清单

1. **严格进程冷启动**：若要完整覆盖冷启动，需要在确认拨号器进程确实结束后重测；当前只确认从 App 首轮进入及连续重复请求。仍只打开拨号盘，不拨出。
2. **拨号护栏**：等待时锁屏、急停或断开会话，不继续操作；清空测试号码。
3. **AirPods 兼容性与持续性**：本次手动往返通过；其他设备、多轮稳定性及实际有声输出尚未测试。
4. **失败后恢复（未通过，先修复）**：入盒失败期限已验证；出盒后的新请求恢复不稳定，需修复后重新验收。
5. **取消及并发**：手机接管期间撤销原手机会话、或 Mac 原生操作期间断开宿主桥连接，旧操作不得继续后续步骤或报告成功；重叠手动请求返回 busy，原请求可正常结束。
6. **自动切换回归**：后续方便播放媒体时验证自动抢占与释放，不影响另一副已配对耳机；这项尚未验证。

其他保留项：TTS/紧急语音按用户要求跳过；实际呼叫、双卡、挂断和免提未授权执行；PIN 未配置。v1.5.6 已通过的镜像、急停、热点锁屏和图案解锁测试不等同于 v1.5.7 全量真机通过。
