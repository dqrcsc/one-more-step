# v1.6.4 · 相册多选与通用文档快传、macOS 原生菜单栏/速览 HUD 与全栈安全功耗优化

> 2026-11-15 源码复核勘误：以下描述已按已发布 v1.6.4 的实际行为校正。后续修复见 [v1.6.5 更新说明](v1.6.5.md)和[修复记录](../review-fixes-2026-11-15.md)。

新增手机端相册多图与通用文档（PDF / Word / Excel / PPT / Markdown / ZIP）一键快传、macOS 原生无 Dock 菜单栏与内嵌速览浮窗（`oms-mac-hud`），并完成全栈安全边界、蓝牙/局域网传输可靠性、三级语音播报路由及后台功耗/磁盘治理优化。

## 新增能力与交互升级

- **手机端相册多选与通用办公文件快传**：
  - **下拉控制中心快捷磁贴半屏快传面板（`QuickSendSheetActivity`）**：点击快捷磁贴不再仅抓取剪贴板，而是弹出轻量无遮挡半屏面板，提供「🖼️ 发相册图片（多选）」「📄 发文件（PDF/Word 等）」「📋 发剪贴板」「🎙️ 按住发语音」四大一键入口。
  - **系统分享菜单增强（`ShareReceiverActivity`）**：同时支持单文件（`ACTION_SEND`）与多选批量投递（`ACTION_SEND_MULTIPLE`），覆盖 `image/*`、`application/pdf`、Office 文档（`.doc`/`.docx`/`.xls`/`.xlsx`/`.ppt`/`.pptx`）、文本/Markdown 与 ZIP 等常见类型（原版未统一执行数量和单文件限制）。
  - **保留原始中文文件名与媒体类型（`AttachmentResolver`）**：通过 `OpenableColumns.DISPLAY_NAME` 提取真实文件名并清洗路径字符，协议与本地数据库支持 `file` 媒体类型，Mac 收件箱落盘保留原始扩展名与可读文件名。
  - **可选相机新拍照片悬浮胶囊（`ScreenshotPillController`）**：除系统截屏外，新增可选开关支持对 `DCIM/Camera` 新拍照片弹出「发送到 Mac」胶囊（原版缺省开启，可在 App 主界面关闭；本轮修复调整缺省值）。
- **macOS 原生菜单栏与内嵌速览浮窗（`oms-mac-hud` + `MacHudServer`）**：
  - **彻底告别 `Script Editor.app` 弹窗与外部应用打断**：新增原生无 Dock Swift AppKit 助手 `oms-mac-hud`（`LSUIElement`），彻底替代原先 `display notification`（点击会唤起脚本编辑器）与自动拉起 `Preview.app` 的打断式行为。
  - **右上角无焦点抢占毛玻璃卡片通知**：收到手机投递的图片、PDF/Word 文档、语音、文本或验证码时，在屏幕右上角弹出毛玻璃悬浮卡片（不抢占当前输入焦点），支持一键「查看详情」或「复制（直接 `⌘V` 粘贴文件/图片/文本）」。
  - **原生内嵌速览浮窗（免打开外部应用）**：内置 `NSImageView`（高清大图缩放）、`PDFKit`（原生多页 PDF 滚动阅读）、`QuickLookUI` `QLPreviewView`（免打开 Word/WPS 原生渲染 `.docx`/`.xlsx`/`.pptx`/文本）与 `AVAudioPlayer`（语音试听 + SenseVoice 转写稿对照），同时常驻顶部菜单栏图标随时查看最近 20 条收件记录。

## 全栈安全、可靠性与功耗治理

- **Web 控制台与本地权限加固**：
  - Web Dashboard 仅允许本机回环访问，非回环请求被拒绝；同时拦截跨源 `POST` 请求（校验 `Origin` / `Host`），镜像 WebSocket 使用独立鉴权。未实现此前说明中的 `oms_token` Cookie 访问模式。
  - 统一 `oms pair` 离线预生成配对码与守护进程运行时配对码的过期时间校验；修复剪贴板敏感密码管理器来源过滤逻辑与 OTP 正则上下文校验。
  - Android 端收紧 `OmsAccessibilityService` 窗口事件采样范围，移除个人测试设备蓝牙 MAC 硬编码默认回退；原版 OTA 比较版本及摘要元数据后打开浏览器下载，未对下载后的 APK 执行应用内 SHA-256 校验，最终由系统安装器检查安装资格。
- **传输稳定性与三级语音播报路由**：
  - 修复 Swift 蓝牙桥 `oms-bt-bridge` 父进程退出孤儿驻留问题（监听 `STDIN` EOF 自动退出），为 `IPCClient` 与桥接握手增加显式超时与缓冲区上限，并为 `DeliveryPolicy` 队列补齐磁盘持久化防丢。
  - 手机语音播报重构为三级路由策略：普通播报默认 `alarm_respect_headset`（闹钟声道，尊重耳机路由）；媒体声道可显式选择；寻机或紧急播报使用 `alarm_force_speaker`。
- **后台功耗、内存与磁盘配额治理**：
  - Android 端 `AT_DESK` 蓝牙已连接状态下暂停后台 mDNS 持续扫描；屏幕熄灭时挂起 `Presence` 传感器高频采样与 `UsageStatsManager` 轮询；`ScreenCapturer` 复用单实例 `VirtualDisplay` + `ImageReader` 消除每秒重建开销。
  - Mac 原版仅清理 `pulled_cache` 暂存文件，未实现500条/2GB收件箱配额，也不会自动淘汰已索引记录与附件。
