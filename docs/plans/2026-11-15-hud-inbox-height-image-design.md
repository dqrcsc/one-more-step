# 投递窗口高度、钉住与图片放大

用户截图明确选中最近投递。上一轮只扩展镜像高度，本轮将两个 Tab 的进入/打开/恢复及跨屏均适配显示器可用最大高度；仍保留手动缩小。新投递同步不抢改尺寸。

钉住开启应保持投递窗口可见并置顶，关闭则投递失焦收起；镜像沿用保持显示策略。先核验 AppKit hidesOnDeactivate、窗口层级、按钮 title 与 attributedTitle，修复实际偏差，提示明确说明行为。

点击投递图片打开原生独立查看窗，支持 +、−、适应、100% 和关闭/Esc，保持原图数据与投递选择。使用 NSScrollView 原生缩放/滚动；不新增外部依赖、不启动外部 App。查看图片时不能因主窗失焦而收起主窗；关闭查看窗返回主窗。主窗关闭、切 Tab 或最小化时关闭图片窗，避免残留。

验收：真实 AppKit 合成长图、按钮动作、图片点击事件、缩放/关闭、钉住状态与失焦语义，及现有 WebKit 模拟回归。只更新本地 Mac 必要文件并备份重启；手机测试继续暂停，不推送 GitHub。
