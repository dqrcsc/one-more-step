# 镜像 Tab 屏幕适配与交互复核

用户明确要求：继续检查界面和交互，默认使用显示器可用最大高度，避免每次拉伸；手机真机验收继续暂停。

采用方案：进入或重新打开镜像 Tab 时，高度等于所在显示器 visibleFrame 高度，宽度保持现有值并受屏幕限制。用户仍可手动缩小；窗口更新/新投递不能反复抢改尺寸。跨屏时重新适配。投递页沿用现有尺寸策略。不使用系统全屏，不新增偏好项；只记忆上次高度无法满足不同显示器的可用高度，而不断强制最大化会阻止手动调整。

复核范围：最小化恢复、关闭/Esc、失焦、缺失入口/失败重试、钉住提示、窄窗口和横竖屏画面几何尺寸。只有证实的问题才修复，不改变手机协议或动作权限。

验收：真实 AppKit 和 WKWebView，隔离 loopback 模拟服务。进入镜像达到可用高度、宽度不变；手动缩小可行；重新进入恢复最大高度；最小化后恢复到未开始页面；横竖屏画面与控制栏在视口内且等比。关闭释放观看连接，不影响其他观看者。本地构建并部署通过验证的 Mac 修复，备份后重启所需进程；不启动真机镜像，不自动推送 GitHub 或发布版本。
