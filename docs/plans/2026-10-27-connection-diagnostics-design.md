# 连接诊断设计

用户已确认补充离线原因提示和连接诊断日志。采用 UI 提示 + 本机有界日志；仅改提示无法保留锁屏现场，远端遥测单独使用又无法解释离线，因此两端保留连接事件，手机离线可复制。

- 手机区分未配对、旧配对、无 Wi-Fi、正在连接、Mac 不可达、连接断开、握手超时、安全校验失败、已连接。正在重试不覆盖上次失败；备用链路错误不覆盖已连接或 LAN 原因。
- 只记录时间、固定事件码、链路和本地尝试编号；禁止原始异常消息、URI、密钥、正文、屏幕、设备身份。手机最多保留 200 条，连续同类重试合并；文件失败不影响连接。
- 手机“连接诊断”对话框显示原因、建议、最近事件，手动复制后可粘贴给排查者。旧日志明确是历史；启动不复用旧在线状态。
- Mac 记录带时间/连接编号的打开、认证成功、失败和关闭事件。安全错误不输出帧或异常原文。
- 不改变握手协议、信任/重试策略，不自动重配，不声称超时等于 AP 隔离。
- 验收：JVM 原因优先级/去重/持久化/上限/敏感异常测试；Bun 日志事件与失败链路回归；类型检查、Android 构建；真机查看与复制需候选 APK 安装后验证。
