## 行为与兼容性选择

- 修复阶段不发布或部署；后续经用户授权发布 v3.6.4 / build 67，日常 Mac 目录和手机仍需另行升级。
- 非无痕聊天仍同步到当前选择且已配对的 Mac；现在每台 Mac 独立记录同步进度，首次选择另一台电脑会补齐该手机的非无痕历史。无痕聊天继续排除。
- 待发收藏绑定产生操作时的 Mac；切机不会把已有待发收藏投给另一台电脑。旧版没有目标的队列在升级初始化时绑定当时选择的 Mac，绑定后不随切机改变。
- 升级后旧的 `synced_to_mac` 布尔字段保留用于兼容显示，但不再作为发送判据。首次会重新建立按目标的确认记录；Mac 接收聊天本来按 ID upsert，不会因此复制聊天记录。
- 旧的未分设备缓存保留在磁盘，不自动猜测归属。已有本地归档继续可读；来源不明时不按文章 ID 请求当前电脑，避免读错内容。
- 远程解锁要求两端更新：旧 Android 不会回传挑战，在 WAN 下会安全拒绝。局域网路径不新增生物识别步骤。
- 生物识别仍由可信的已配对 Android 客户端执行。挑战防止陈旧确认跨连接/重复使用，但不是硬件签名的生物识别证明；本轮没有引入设备证明或生物识别密钥注册协议。
- 幂等登记从本次版本开始生效，无法可靠追溯旧版未保存 itemId 的知识库文件。已有文件不自动删除或改名。
- 保留现有系统 API 弃用警告，不做无关格式化或整仓重构。
